# NutriMind AI

AI-powered food and health intelligence platform.

## Goal
Help users build healthier eating habits using contextual AI insights.

## Features
- Google Authentication
- Food image upload
- Gemini Vision analysis
- Personalized nutrition recommendations
- Daily health score
- Meal tracking

## Stack
- Next.js
- TypeScript
- TailwindCSS
- Firebase Auth
- Firestore
- Firebase Storage
- Gemini API
- Cloud Run
- Docker

## Requirements
- Production-ready
- Responsive
- Accessible
- Secure API handling
- Clean architecture
